# Homebrew Tap for VoiceStudio 🎙️

Official Homebrew Cask tap for **[VoiceStudio](https://github.com/saadmsft/VoiceStudio)** — the ultra-lightweight (~0.4% CPU) native macOS real-time broadcast voice rack.

## Install

```bash
brew install --cask blackhole-2ch
brew install --cask saadmsft/tap/voicestudio
```
